# Web-Based Dental Clinic Management System

A web-based system designed to manage and streamline dental clinic operations.

## Project Overview

This system provides digital solutions for managing dental clinic activities such as:

- Patient Management
- Doctor Management
- Appointment Management
- Prescription Management
- Medicine Management
- Inventory Management
- Supplier Management
- Purchase Order Management

## Technologies

### Backend
- Java
- Spring Boot
- MySQL

### Frontend
- React
- Vite

## Team

This project is developed as a group project.
