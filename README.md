# Web-Based Dental Clinic Management System

A full-stack web application developed to streamline dental clinic operations by managing patient records, appointments, treatments, prescriptions, billing, and inventory through a centralized system.

## Project Overview

The **DentaFlow Dental Clinic Management System** provides digital solutions for managing daily clinic activities, improving operational efficiency, and maintaining organized patient and administrative records.

### Core Features

- Patient Management
- Doctor and Staff Management
- Appointment Management
- Treatment, Prescription & Billing Management
- Invoice and Payment Management
- Medicine Management
- Inventory Management
- Supplier Management
- Purchase Order Management
- User Authentication and Role-Based Access Control

## Technologies Used

### Backend
- Java
- Spring Boot
- Spring Security
- JWT Authentication
- MySQL

### Frontend
- React
- Vite
- JavaScript
- CSS

## System Architecture

The frontend communicates with the Spring Boot backend through REST APIs. The backend processes business logic and interacts with the MySQL database to store and retrieve application data.

## Design Patterns

The **Strategy Design Pattern** is implemented in the relevant business logic to promote modularity, maintainability, and extensibility.
